# Data

The FORCE 2020 dataset is not included in this repository due to size.

## Download Instructions

1. Create a Kaggle account: https://www.kaggle.com/
2. Download from: https://www.kaggle.com/datasets/faresazzam/well-logs-dataset-for-machine-learning
3. Place CSV files in this folder (`/data/`)

Or run the notebook - it downloads automatically using the Kaggle API.
